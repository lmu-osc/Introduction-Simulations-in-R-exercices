This repository contains the exercices R script of the tutorial 'Introduction-Simulations-in-R' https://lmu-osc.github.io/Introduction-Simulations-in-R/  

You can fork and clone the repo to get them locally, or you can download this repo as a zip file. 

You can choose between an exercice R script with or without the solutions depending on e.g. your level of familiarity with R.
